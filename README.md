# About

Userscript to make new overlay gallery and template tools from Wplace's September 2026 update have a UX more similar to the old one without removing new features. 

Currently in beta. Bugs are expected.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open [this link](https://raw.githubusercontent.com/vwbeetle/wplace-overlay-gallery-tweaks/main/wplace-overlay-gallery-tweaks.user.js) and Tampermonkey should prompt you to install the script
3. Reload wplace.live
